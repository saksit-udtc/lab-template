## 📋 วิธีส่งงาน (สรุปย่อ)

### ขั้นตอนครั้งแรก (ทำครั้งเดียว)
1. กด Accept Assignment จากลิงก์ที่ครูส่งให้ หรือกด **Use this template** ที่หน้านี้
2. GitHub จะสร้าง repo ส่วนตัวให้อัตโนมัติ
3. กด Code → Download ZIP หรือ git clone ลงเครื่อง

### ขั้นตอนส่งงานแต่ละ Lab
1. เปิดไฟล์ pcap ด้วย Wireshark จาก https://github.com/saksit-udtc/network-security-lab
2. กรอกคำตอบในไฟล์ answers/lab01.yml (หรือ lab ที่ได้รับมอบหมาย)
3. Push ขึ้น GitHub ระบบจะตรวจและให้คะแนนอัตโนมัติภายใน 1 นาที
4. ดูคะแนนได้ที่ tab Actions ใน repo ของตัวเอง
